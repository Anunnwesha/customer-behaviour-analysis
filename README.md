# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using a dataset containing **3,900 purchase transactions**. The goal is to identify customer spending patterns, purchasing preferences, subscription trends, and product performance to generate actionable business insights.

## 🛠️ Tools & Technologies

* **Python** – Data cleaning, preprocessing, and Exploratory Data Analysis (EDA)
* **Pandas** – Data manipulation and analysis
* **PostgreSQL** – Database management and SQL-based business analysis
* **SQL** – Customer segmentation, revenue analysis, and product performance analysis
* **Power BI** – Interactive dashboard and data visualization

## 📊 Key Analysis

* Revenue comparison by gender
* Identification of high-spending customers using discounts
* Top-rated products based on customer reviews
* Comparison of Standard and Express shipping purchase amounts
* Subscriber vs. non-subscriber purchasing behavior
* Identification of discount-dependent products
* Customer segmentation into New, Returning, and Loyal customers
* Top 3 best-selling products within each category
* Analysis of repeat purchases and subscription behavior
* Revenue contribution by customer age group

## 🔍 Project Workflow

1. Imported and explored the shopping dataset using Python.
2. Cleaned missing values and standardized column names.
3. Created new features, including age groups and purchase frequency.
4. Connected Python with PostgreSQL and loaded the cleaned dataset.
5. Executed SQL queries to answer key business questions.
6. Created an interactive Power BI dashboard to visualize the findings.
7. Developed business recommendations based on the analysis.

## 💡 Business Recommendations

* Encourage customer subscriptions through exclusive benefits.
* Introduce loyalty programs to reward repeat customers.
* Optimize discount strategies to balance sales and profitability.
* Promote top-rated and best-selling products.
* Focus marketing campaigns on high-revenue customer segments.

## 🎯 Project Objective

The objective is to transform raw shopping transaction data into meaningful business insights that help improve customer retention, marketing strategies, subscription growth, and sales performance.
